# Governance

BetterButtons is currently maintained by Alexander Svensson.

## How decisions are made

- Bug fixes and documentation changes can be accepted through normal review.
- New public classes, breaking changes and large visual directions should begin with an issue.
- Decisions prioritize accessibility, a small runtime surface, composability, browser resilience and long-term maintenance.
- When there is no clear consensus, the maintainer makes the final decision and records the reasoning in the issue or pull request.

## Releases

The maintainer owns versioning, npm publication and GitHub releases. No contributor is expected to hold release credentials. The documented release checklist must pass before publication.

## Becoming a maintainer

Consistent, constructive contributions may lead to expanded review or triage permissions. Commit access is granted deliberately and follows least privilege. This document will be updated if the maintainer group grows.
