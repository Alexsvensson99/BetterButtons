# Support

Choose the channel that keeps the answer useful to everyone:

- Ask focused implementation and customization questions with the question issue form.
- Report reproducible defects with the bug issue form.
- Propose public API changes with the feature issue form.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

Include your BetterButtons version, browser, reduced-motion or forced-colors settings when relevant, a minimal HTML example and what you expected to happen.

Maintainers help on a best-effort basis. There is no guaranteed response time or private integration support.
