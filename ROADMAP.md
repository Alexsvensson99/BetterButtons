# Roadmap

The roadmap describes direction, not a delivery promise. Priorities can change based on accessibility findings and contributor feedback.

## Now

- Stabilize the 2.0 CSS class and token contract.
- Validate installation from a packed npm tarball.
- Maintain repeatable accessibility, responsive, visual regression and package checks.
- Prepare the repository for its first public open-source release.

## Next

- Publish the first npm package and signed GitHub release.
- Document framework-specific integration examples without adding runtime dependencies.
- Test more forced-colors and high-contrast combinations with assistive technology.

## Later

- Evaluate logical-property and right-to-left refinements.
- Explore a reduced core build and optional theme bundles.
- Consider community-maintained adapters only where they do not fragment the CSS API.

Propose roadmap changes through a feature issue with a concrete user need and maintenance impact.
